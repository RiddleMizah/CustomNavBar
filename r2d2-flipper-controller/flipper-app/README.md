# Flipper Zero R2-D2 Remote

This Flipper app exposes a purpose-built Bluetooth HID remote for the companion Android tablet app.

## Controls

- **Drive mode:** D-pad drives/turns; releasing a direction stops R2-D2; OK sends emergency stop.
- **Head mode:** Left/right move the head, OK centers it, up/down trigger wake and whistle sounds.
- **Extras mode:** Left/right set red/blue, OK turns the lights off, up/down trigger wake and whistle sounds.
- **Short Back:** cycle modes.
- **Hold Back:** exit.

Pair it to the tablet as a Bluetooth keyboard/remote, then keep the Android companion app in the foreground.
